Cookie & Local Storage Policy

Last updated: 25 October 2026

Current implementation note: The inspected page uses browser local storage for an alerts preference. Local storage is not technically a cookie, but this policy explains similar browser storage. Verify all current scripts before publishing.

1. What is stored

Browser storage may remember a user preference such as whether spoken alerts are enabled. Authentication may also use a session token or other browser storage depending on the deployed account implementation. Document the exact key names, purpose, expiry and whether each item is strictly necessary after checking the current code.

2. Essential storage

Storage required for sign-in security or a feature the user explicitly requests may be necessary to provide that service. Do not use essential storage for advertising or unrelated tracking.

3. Analytics and advertising

The inspected HTML did not show common Google Analytics or Tag Manager code. Do not add analytics, advertising trackers, or non-essential identifiers without updating this notice and implementing any consent required by applicable law. If optional analytics are added, keep them off until the user makes an informed choice where consent is required, and provide a way to change that choice.

4. Third-party requests

Map assets, map tiles and nearby-place searches contact third-party services. Those services may receive technical request information and query data. See the Privacy Policy and the providers' own notices.

5. Managing preferences

Users can clear browser storage through their browser settings, but doing so may sign them out or reset preferences. Provide in-app controls for optional preferences where practical. Do not make optional tracking a condition of using core convoy features.
