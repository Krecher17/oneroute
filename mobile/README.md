# ONEROUTE Android app

This is a separate Android app for the existing ONEROUTE server. It does not
modify or copy-edit the server project. The deployed ONEROUTE application is
loaded directly inside the app's embedded Android WebView; it is not handed
off to Chrome or another external browser.

The default website is:

```text
https://oneroute.dpdns.org
```

## Local setup

```powershell
npm install
npx cap add android
npx cap sync android
```

The Android build also requires JDK 21, an Android SDK, and either Android
Studio or the Gradle wrapper generated by Capacitor.

## Connect a device

- The deployed website is configured as the app's embedded start page.
- For local testing, start the existing server with `npm start`, find the
  computer's LAN IP, and enter `http://<LAN-IP>:3001` in the app.
- Android emulator local server: use `http://10.0.2.2:3001`.
- The phone and computer must be on the same network, and Windows Firewall
  must allow inbound TCP traffic on port 3001.
- For production, use an HTTPS server URL instead of a local HTTP address.

## Build and run

```powershell
npx cap sync android
npx cap run android
```

The generated Capacitor 7 project uses Java 21 for the native Android build.
